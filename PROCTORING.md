# 🚀 How to Use ExamX for the Assessment

Follow these steps carefully.

---

## 1️⃣ Install ExamX Extension

1. Open Visual Studio Code.
2. Go to Extensions (`Ctrl + Shift + X`).
3. Search for **ExamX**.
4. Click **Install**.

---

## 2️⃣ Open a New VS Code Window

After installing:

- Open a **new VS Code instance**.
- Open the provided assessment project folder.
- Do NOT use an existing VS Code session with multiple workspaces open.

This ensures clean monitoring.


## 4️⃣ Connect to Examiner

Click **Login**.

You will be asked to:

- Enter your registered email address
- Complete email verification
- Enter the **Exam Passcode** provided by the examiner

Only after successful verification will the exam be enabled.

---

## 5️⃣ Start the Exam

Once verified:

Click **Start Exam**.

What happens next:

- A timer will appear at the bottom-left.
- Monitoring begins.
- Activity logging starts.
- Clipboard and focus events are tracked.

The exam session is now active.

---

# ⏳ Timer Behavior

- The timer runs continuously once started.
- If time runs out:
  - The project is automatically submitted.
  - The session is locked.
- You may manually submit before time ends.

---

# 📤 Submitting the Exam

You can submit in two ways:

1. Click **Submit Exam** (if available).
2. Let the timer expire (auto-submit).

Once submitted:

- The session ends.
- Logs are uploaded.
- Further edits are tracked.
